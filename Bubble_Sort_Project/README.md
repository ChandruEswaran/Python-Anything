# Bubble Sort Project

Sorting is easier to understand when you can watch the numbers move. This interactive project lets you enter a list and compare bubble sort in ascending or descending order.

## What it can do

- Accept a list of numeric values
- Show the original list
- Sort in either direction
- Display comparison, swap, and pass counts

## Run it

From this folder, run:

```bash
python main.py
```

Python 3 is required; no extra packages are needed.

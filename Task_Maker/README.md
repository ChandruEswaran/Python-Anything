# Simple Task Maker

Keep a few everyday priorities in view with a small, menu-driven task manager. Add tasks, look up their details, make changes, and remove completed or unwanted items.

## What it can do

- Add tasks with a description, due date, and priority
- View all tasks or find one by name
- Update or remove a task

## Run it

From this folder, run:

```bash
python Task_manager.py
```

Python 3 is required; no extra packages are needed. Tasks are kept in memory and are cleared when the program exits.

# Student Grade Management

A simple way to keep student records and marks organized. This menu-driven app stores student information locally and turns subject scores into individual reports.

## What it can do

- Add, search, list, and remove students
- Enter marks for each subject
- Generate student reports
- Store records in a local SQLite database

## Run it

From this folder, run:

```bash
python main.py
```

Python 3 is required; no third-party packages are needed. The app creates its database tables when it starts.

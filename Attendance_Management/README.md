# Attendance Management System

A small, practical way to keep member records and daily attendance together. This menu-driven Python app stores its data in SQLite and turns attendance into useful reports.

## What it can do

- Add, find, update, and remove members
- Mark and review daily attendance
- View daily summaries, monthly reports, and individual histories

## Run it

From this folder, run:

```bash
python main.py
```

Python 3 is required. No extra packages are needed. The app creates its SQLite database and tables when it starts.
